# Quarter-Car Euler 積分模擬

[Download Code](quarter_suspension_int.py)

## 簡介

本分析使用顯式 Euler 方法，從靜態平衡位置開始模擬 quarter-car 懸吊系統在路面階躍輸入下的簧上位移與加速度。模型包含簧上質量、簧下質量、懸吊彈簧、輪胎剛性與阻尼器。

相較於使用 ODE solver 的版本，此程式將每一步受力、加速度、速度與位置更新明確寫出，適合用來檢查懸吊力平衡與數值積分流程。

## 參數

以下為計算中所採用的物理量與符號說明：

| 變數名稱 | 物理意義 | 單位 |
| --- | --- | --- |
| `ms` | 簧上質量 ($m_s$) | $kg$ |
| `mu` | 簧下質量 ($m_u$) | $kg$ |
| `ks` | 懸吊彈簧剛性 ($k_s$) | $N/m$ |
| `kt` | 輪胎剛性 ($k_t$) | $N/m$ |
| `c` | 阻尼係數 ($c$) | $N \cdot s/m$ |
| `zs`, `zu` | 簧上與簧下位置 | $m$ |
| `vs`, `vu` | 簧上與簧下速度 | $m/s$ |
| `zr` | 路面高度輸入 | $m$ |
| `dt` | 積分時間步長 ($\Delta t$) | $s$ |
| `T_end` | 總模擬時間 | $s$ |
| `a_s`, `a_u` | 簧上與簧下加速度 | $m/s^2$ |

## 計算

### 1. 靜態平衡初始化

程式先根據重力與彈簧剛性計算輪胎壓縮量與簧上初始位置，使系統從靜態平衡附近開始：

$$F_{u,i} = -(m_s + m_u)g$$

$$F_{s,i} = -m_s g$$

$$z_u = \frac{F_{u,i}}{k_t}$$

$$z_s = z_u + \frac{F_{s,i}}{k_s}$$

### 2. 受力計算

每個時間步中，懸吊彈簧力、阻尼力與輪胎力分別為：

$$F_s = k_s(z_u - z_s)$$

$$F_d = c(v_u - v_s)$$

$$F_t = k_t(z_r - z_u)$$

### 3. 加速度與 Euler 更新

簧上與簧下加速度為：

$$a_s = \frac{-m_sg + F_s + F_d}{m_s}$$

$$a_u = \frac{-m_ug - F_s - F_d + F_t}{m_u}$$

速度與位置使用顯式 Euler 方法更新：

$$v_{i+1} = v_i + a_i \Delta t$$

$$z_{i+1} = z_i + v_{i+1}\Delta t$$

### 4. 路面階躍

程式在 $t > 1.0\text{ s}$ 後將路面高度改為 $0.05\text{ m}$，用來模擬車輪通過一個簡化 bump。

## 結果

程式會輸出簧上位置與簧上加速度隨時間變化，並計算最大簧上位置與最大簧上加速度。若執行程式產生 `quarter_car_euler_response.png`，建議將該圖放在本資料夾並於此段落加入置中圖片。

此結果可用於觀察顯式 Euler 方法下的懸吊暫態反應，並與 ODE solver 版本比較數值穩定性與響應差異。
